# SMS Spam Detection

## Project Overview
This project is a machine learning web application that detects whether an SMS message is Spam or Not Spam (Ham). It features a full data processing pipeline and a web-based GUI for real-time predictions.

## Dataset & Methodology
* **Dataset:** UCI SMS Spam Collection
* **Preprocessing:** Data cleaning, stopword removal, and TF-IDF vectorization
* **Model:** Naive Bayes (MultinomialNB) classifier
* **Frontend:** Streamlit
